# 零压拆船厂 · 开发目录（2026-10-15 修订）

七个大阶段，每个阶段下面是按顺序做的小阶段。勾选 = 已完成。
依据：DECISIONS.md（含「合同循环 v2」与补充决定）、《新手教程与剧情》策划案、用户的 8 船型设定、用户 2026-10-15 的路线图修改意见。

**贯穿全程的验收规则**：从阶段一起，每个小阶段完成时都必须跑**存档往返测试**（船体结构、切口形状、管线状态、零件位置、已发生的事故全部一致）和**性能回归测试**（最坏情况稳 60 fps）。阶段七只做最终检查，不再补课。

## 阶段一 · Demo 完善（单艘灰鹭号，能交给别人玩）
- [x] 1.1 稳定性与手感：飞行稳定（F）、字体减重、辉光与顿帧特效、修闪退、随机压力测试（待用户试玩确认）
- [ ] 1.2 性能优化（目标：1080p 下最坏情况也稳 60 fps，任何一帧不超过 25 ms）
  - 测出最坏情况：同时切割、整舱失压、30 个以上漂浮件、拖运中，记录每个子系统的帧耗时
  - 静态船体层：每切一刀整层重绘约 20 ms → 改为按区块分层，只重绘被切的那一块
  - 切口多边形瘦身：长切缝后顶点数会涨，提交时简化，碰撞体用更粗的版本
  - 碰撞体重建、连通性计算、气压网格：只更新受影响的区域，并控制每帧的工作量
  - 特效：粒子、雾气、火花设上限并批量绘制；HUD 文字缓存
  - 结果写进 perf 测试，之后每次改动都能回归
- [ ] 1.3 存档加固：存档格式加版本号与迁移；损坏时自动从备份恢复；往返测试覆盖船体结构、切口、管线与阀门状态、零件位置、已发生的事故与读数
- [ ] 1.4 船型数据化：灰鹭号改为「通用构建器 + 船型数据」，训练舱段 TS-1 用同一套框架搭（第一次验证“加船只加数据”）
- [ ] 1.5 训练舱段 TS-1：六课（前四课锁步、后两课目标式）、危险动作拦截、零压认证
- [ ] 1.6 灰鹭号三档提示（引导 / 标准 / 硬核）+ 训练回想卡
- [ ] 1.7 剧情：七件可检查物件、魏岚台词、黑匣子尾声录音、#002 白鹭号钩子
- [ ] 1.8 学徒考核 + 事故复盘

## 阶段二 · 合同循环（灰鹭号可以反复拆、越拆越强）
- [ ] 2.1 生涯存档 + 首单后开放拆船公司：终端三标签页（合同市场 / 设备商店 / 船坞管理）骨架
- [ ] 2.2 变体生成器：基于船型数据（不写死灰鹭号），生成危险配置、货物、事故破损、图纸偏差
- [ ] 2.3 合同验证器：每份生成的合同在上架前自动检查
  - 可拆解：每个零件都有一条在当前工具能力内的拆卸路径，强制回收件可达
  - 有证据：每个故障在后果发生前都能被测到或看到
  - 不自燃：生成后静置 60 秒不发生任何事故
  - 机器人按规程拆一遍能拆完；不通过的合同丢弃重抽
- [ ] 2.4 招牌陷阱池 10 种 + 风险星级 + 声望等级（每种陷阱都要过验证器）
- [ ] 2.5 钱：先付合同费、软时限奖金、贷款强制分期、还清里程碑
- [ ] 2.6 设备商店首批升级：精密检测套件、5 吨抓钩、高效泵、工业回收机械臂（初级）；升级在画面上看得见
- [ ] 2.7 消耗品：维修包、爆破切割环、备用无人机、情报包
