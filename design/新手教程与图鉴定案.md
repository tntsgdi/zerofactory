### 基础训练八课

1. 到岗
2. 先学会看：飞行 / 刹车 / 飞行稳定 → **镜头（右键拖动平移、Z 拉远看全船）与悬停锁定 V** → **情境工具（指着螺栓左键就拧）** → 测量 → 蓝图
3. 你的第一块废料：拆螺栓、抓钩、送熔炉
4. **熔炉与回收口（新）**：三个回收口各收什么、底部长槽、6–8 m 外远远甩进去、熔炉读数（炉温、熔池、出钢）
5. 零不等于安全：测压 / 查管路 / 关阀 / 软管放气
6. 关机不等于断电：验电 / 断备用电源 / 放电
7. **失重液体（新，锁步骤）**：先接软管排空再切；再故意切开一根满管，看液团漂出、碰到带电件短路
8. 你漏了一根管线（目标式拆冷却泵，漏掉的管线切到也会喷液团）
9. 重的东西不听话（超 3 t）

（课号以实现为准：到岗是第 0 课。）

### 专项训练 7 门与船的归类（Q20 / Q24）

| 大类 | 船 | 练习件 | 学会的规矩 |
|---|---|---|---|
| ① 储能 | FX-70、MD-160、PT-34、PS-12、H-22、CV-138 | 小超导线圈、小飞轮、液压预紧件 | 先测储能；线圈先接泄能电阻放电归零再断冷（反过来失超，联锁演示一次）；飞轮制动到 0 再拆；预紧件先泄压 |
| ② 低温 | QC-30、HG-170、FR-26、CL-104、IC-120 | 小低温罐（安全阀冻住）、稀释制冷机模型 | 罐压自己会升；冻住的阀先解冻或从接口放空；制冷机按级从冷到热依次回温 |
| ③ 流体压力 | DR-150、VT-80、DC-84、BL-88、FL-116 | 一段钻杆、两只连通罐 | 钻杆泄扭 → 泄压 → 松卡瓦、自上而下；连通罐先关连通阀再抽，否则吸瘪；外观相同的介质先测再接 |
| ④ 气氛、火与污染 | HB-86、MY-48、ST-40、NR-95、EV-55、MF-126、MED-47 | 富氧小舱、复合材料板、热件 | 富氧先换气再开激光；复合材料别切，改用扳手或先把舱抽真空；关机不等于冷却，先读温度 |
| ⑤ 受力与运动 | TW-64、CH-110、CF-90、SA-200、IH-55、TB-180、MT-140、M-14、JD-38、RO-128、SV-122、ARK-01 | 四个对称夹钳、张力缆、一段锁轨 | 交叉成对松；先泄张力再切；锁轨货物沿轨出、出轨要减速 |
| ⑥ 精密件 | OB-90；HB-86、PS-12、BL-88 的玻璃 | 镜面、促动器、观景窗 | 镜面旁不切割，先上防尘罩；先锁促动器再搬；窗先泄压再拆框 |
| ⑦ 隔离与取出 | ES-112、LC-140 | 双路供电门锁、船中船模型 | 断一路不算断电，备用电源会倒灌，两路都断才扳释放杆；船中船先断全部连接再整体拖出 |

作业艇、S-09、GR-001、货运吊舱只用基础训练教过的东西，不需要专项章。含两个大类：HB-86（④⑥）、PS-12（①⑥）、BL-88（③⑥）。
