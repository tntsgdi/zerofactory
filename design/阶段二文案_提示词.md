# 给写作 AI 的提示词：《零压拆船厂》阶段二文案

> 用法：把从「你要写的是」到文末的全部内容，原样交给写作 AI。它交回的表格直接发给开发这边，按编号导入游戏。

---

## 你要写的是

一款 2D 太空拆船游戏《零压拆船厂 ZERO PRESSURE》第二阶段（合同循环）里的台词和短文字。只写下面「待写清单」里列出的编号，不要增加编号，不要改编号。每一条都要中文；英文可写可不写（不写由开发翻译）。

## 世界与基调

- 近地轨道上漂着一个世纪的退役船，拆船是这里最赚钱、也最容易出人命的行当。行规写在每个泊位的门框上：先归零，再动刀——压力归零、电压归零、温度归零，最后让船本身归零。
- 锈环站（RUST RING）是一座低轨拆船站，玩家接手其中的 BERTH 07 泊位，背着一笔 30 万的贷款。卡戎轨道回收（CHARON ORBITAL SALVAGE）是经营公司：发合同、收合同费、放贷款，不关心船为什么出事，只关心回收率。
- 玩家从不露面，坐在站里通过远程无人机 R-02 工作。
- 基调：安静、克制、工业。没有反派。

## 会说话的角色

**梁工**（BERTH 07 的船坞工程师）。以下是作者原剧本里的人设，必须遵守：
- 资历：从业二十多年的船体回收工程师。
- 性格：务实、冷静、偶尔讽刺，不喜欢无意义的废话。
- 说话方式：短句、自然口语，不用夸张的科幻术语。
- 对玩家的态度：不把新人当傻子，但绝对不允许他忽视危险。
- 特点：经常把昂贵的设备损失换算成钱。
- 不会一直说「干得漂亮」「太棒了」。

作者剧本里梁工的原话，作语气参考：
- 「不确定的东西，先查清楚再动。」
- 「第一笔收入，够买几杯咖啡。先别急着发财，接下来还有正事。」
- 「零倒是零。可它测的是哪儿？」
- 「要是把完整模块直接烧成废铁，老板估计比电容炸了还心疼。」
- 「行，至少你没把船坞一起拆了。」
- 「第一次接正式合同就做到这个程度，挺少见的。老板看了应该高兴。就是别指望他给你涨工资。」

**船坞终端**：只出系统文字和短促合成语音，不带人格、不吐槽、不评价。写法：一行全大写英文 + 一行中文，例如「CONTRACT MARKET OPEN. / 合同市场已开放。」

**船载记录**：报价卡上附带的、出事船只最后留下的记录片段（日志、维修单、交接备注）。是船员写的，可能过时、可能写错，玩家要自己验证。

## 硬性规则

1. 梁工每句不超过约 40 个汉字（念出来约 12 秒），长的拆成两句（编号 _1、_2）。
2. 船载记录每条不超过 30 个汉字，像真实的日志/备注，不要写成提示。
3. 陷阱名称不超过 8 个汉字。
4. 任何文字都不能直接告诉玩家答案（例如不能写「V-C01 是关着的」）；只能让玩家起疑、去测量。
5. 不要新增人物，不要提 KX-0 和灰鹭号事故的真相（那是主线，后面再写）。
6. 灰鹭号里的现有人物（船长伊莎·莫兰、轮机长韩彻、实习货管小路）在阶段二不出场。

## 阶段二在游戏里是怎么回事（写作背景）

- 拆完第一单灰鹭号后，玩家拿到经营权限，船坞终端开放三个标签页：合同市场 / 设备商店 / 船坞管理。
- 合同市场每次给 3 张报价卡，挑 1 张。每张卡有：船型、报废原因、预估可回收价值、合同费、风险星级（1–3 颗），以及 2–3 行船载记录。同一型号（目前只有灰鹭级）每次的危险配置不同。
- 每单至少有一个「招牌陷阱」（见下表）。所有陷阱都能靠测量和观察提前发现。
- 钱：接单先付合同费；在标准用时内完成多拿 20%，超时递减；贷款每单强制扣分期和利息，扣不够就并回贷款；还清时有里程碑「BERTH 07 归你了」。
- 声望四级：见习 → 认证 → 资深 → 首席。声望越高，越危险、报酬越高的单子越多。

## 十种招牌陷阱（写名称、船载记录、复盘说明时用）

| 编号 | 实际情况 | 玩家要做的 |
|---|---|---|
| wrong_valve | 测压口和舱室之间的阀门关着，表上读到的是阀外那一小段空管 | 先开阀再测 |
| fake_stop | 面板显示发电机已停机，实际还在转、母线还有电 | 去测点验电，必要时拉本地手柄 |
| hidden_tank | 某个舱里有一只没登记的高压储气罐 | 打开舱室后先检查、单独抽空 |
| live_cargo | 一只货柜自带电源或冷藏机组，还在通电 | 先验电、断电再拖 |
| welded_hatch | 一扇舱门被焊死，图纸上却是普通门 | 换路线或切开 |
| rerouted_line | 一条管线被改道，和图纸走向不一样 | 沿实物追管线，别信图纸 |
| second_source | 船上有一台应急发电机，独立于主电网 | 找到并隔离第二电源 |
| hidden_damage | 一段主结构有暗伤，拖拽时会突然断开 | 先检查完好度，换受力点或先分段 |
| explosive_cargo | 一批货物是易爆品，误进熔炉会爆燃 | 识别后送危险品回收口 |
| fire_system | 消防系统的灭火剂储罐还带压 | 当作压力容器处理，先泄压 |
