## 1. 视觉语言（全游戏统一）

现在的画面是「白线蓝图」：浅灰底、白色描边，船和港口都像图纸。改版后：

| | 现在 | 改版 |
|---|---|---|
| 底色 | 浅灰平面 | 深石墨色金属板，带板缝、铆点、减重孔 |
| 描边 | 统一白线 | 结构件冷灰边，设备件亮边；只有有信息的东西才发光 |
| 光 | 几乎没有 | **发光 = 系统在运行**（见第 3 节），断电就熄 |
| 舱内 | 空 | 有气压的舱带淡蓝空气感；隔热毯、电缆槽、扶手、灭火器、梯子、绑货环 |
| 船外 | 平板 | 船体发光带、航行灯（左红右绿）、姿控喷嘴、传感器罩、天线、散热片 |

颜色只表达状态，不做装饰：

- **青色**：通电 / 运行中（断电后熄灭或变暗）
- **橙色**：热、切割、危险（沿用现在的激光和熔炉色）
- **绿色**：流体（冷却液、水）
- **蓝色**：气体（氧、氮、舱内空气）
- **紫色**：高能（聚变堆、电容组、推进器磁环）
- **琥珀色**：机械约束（锁扣、束带、货锁灯亮 = 还锁着）

可读性规则：零件始终比舱壁亮一档；HUD、图纸（Tab）、标签不变。图纸仍是线稿，和现场的发光画面正好对照。

## 3. 发光 = 系统状态（新增的现场反馈）

改版最重要的一条：**光告诉玩家哪里还活着**，不用每处都测量。

| 光 | 亮 | 熄 / 变暗 |
|---|---|---|
| 船体发光带、电缆槽里的光点 | 主电源在供电 | 主电源断开 |
| 某个舱的舱灯、睡眠舱灯、终端屏幕 | 这个舱的电路带电 | 这个舱的电路已断开 |
| 全息飞控台投影 | A 舱带电 | A 舱断电 |
| 磁浮托架 | C 舱电路带电（货柜被托住） | 断电后货柜落到托架上 |
| 货锁、束带的琥珀灯 | 锁着 | 解开 |
| 冷却管绿光 | 回路有压 | 排空 |
| 聚变堆约束环 / 电容线圈 | 运行 / 有储能 | 停机 / 已放电 |

陷阱照样成立：独立供电、二号电源、假急停这些情况，灯会**如实**亮着，玩家看得到「我明明断了总闸，这里还亮」。光只反映真实状态，不替玩家判断。

## 4. 需要补的系统（小）

- **B 舱电路**：接两只睡眠舱和食物打印机（现有电缆机制）。
- **水管**：给食物打印机加一根「水」流体线。漏水不算危险品，只让附近设备完好度掉 5%。这是唯一的新流体种类。
- **吊车小车**：挂在 C 舱电路上（现有带电切线电击）；两把导轨锁沿用锁扣。
- **货舱管理终端读货单**（可选新玩法，见第 6 节第 5 条）。
- 其余都是现有机制：储气爆裂、燃料危险品、易碎件、撕扯掉价、冷却液污染。

## 6. 影响与需要你确认的

1. **方向对不对**：深色金属 + 青色运行光 + 全息（见效果图）。偏暗还是偏亮、青色多还是少，告诉我就能改。
2. **新零件清单**：加还是删哪些，价值合不合适。
3. **GR-001 会变长**：新增 27 件零件，按机器人节奏估计整单多 4–6 分钟，价值多约 $18k。
   - 选项 A：GR-001 用全部零件。
   - 选项 B：开局的 GR-001 拿掉货盘和姿控喷嘴，市场上的灰鹭号才有全套（变体生成器本来就会随机拿掉一些零件）。
4. **G-STOP 搬到驾驶舱顶部面板**：好不好。
5. **货舱管理终端读货单**：要不要这个新玩法。不要的话它就只是一件普通设备。
6. **训练船 TS-1、S-09、作业艇、货运吊舱**：以后都用同一套视觉语言（建议是）。

实现顺序（审过以后）：

1. 视觉语言 + 泊位：不动玩法，GR-001 测试基准不变。
2. 灰鹭号原有零件换外观 + 第 3 节的状态灯。
3. 新增零件和第 4 节的小系统。
4. 重定测试基准：GR-001 固定测试、合同验证器、陷阱位置表、变体可删列表、存档模糊测试。
5. 本地看画面验收；性能回归（发光层用现有 HDR 辉光，目标仍是稳 60 fps）。
