# 开发者工作台

在技能书成长版基础上增强开发者模式，主界面改为工业风卡片工作台，不再使用右上角快捷键列表。

## 打开与关闭

F12 开启工作台；再次 F12 或 Esc 收起。收起后调试开关继续生效，右上角只保留一条小状态徽标，点击徽标也能重新打开。右上角“退出开发模式”关闭无敌、透视、检查和开发倍速。它不会撤销已经写入生涯的资金、等级或已进行的拆解。

作业中打开工作台会暂停物理、合同计时与工具输入；关闭后恢复进入前的暂停状态。若原本就在暂停菜单或现场终端里，退出工作台后仍保留原来的暂停。

## 三个工作区

- 作业控制：保留原 F1–F10 功能，以卡片显示用途、快捷键和开关状态。新增恢复无人机与回到机库。终端 F4 现在同时解锁原有设备设施和全部 45 级技能书。
- 成长调试：六类分组卡片，15 条路线分别选择 0 / I / II / III，或一键应用技能预设。现场可选择“当前作业装配”或“生涯永久等级”；终端直接编辑当前生涯。资金金额和声望增量可以输入，扣款不降到负数。永久调整使用候选副本保存，写盘失败时恢复原生涯和现场装配。
- 合同试验：八种船体卡片与对应真实结构预览，保留事故、风险、范围、目标、设备、种子与校验。新增技能等级装配预设。启动与放入报价按钮固定在工作区底部，不会被滚动内容挤走。独立沙盒不结算到生涯；放到市场报价的合同仍按正式生涯合同处理。

调试装配可以真正降回原装：5 t 抓钩等旧升级别名会一起清除，不会出现按钮显示 0 级、实际仍有旧升级的情况。当前作业调试只改现场配置，永久购买记录不变；作业快照沿用现有保存机制，不承诺重开或继续时始终覆盖生涯装配。

## 视觉与操作

顶部四张状态卡显示场景、资金 / 声望、装配等级和模拟状态；现场同时显示耐久与倍速。中部用页签分区，操作是卡片按钮与等级分段按钮。支持鼠标、滚轮、Tab / Enter；中英文与 1280×720 窗口已截图检查。

## 验证

`tests/workbench_check.gd` 的 24 项断言通过；`tests/dev_check.gd` 的 25 项原有开发功能检查通过；71 项技能书检查及 13 项船坞终端检查通过。隔离 Windows QA 导出使用与正常发行包一致的 57 个生产脚本，12 项打包检查通过，其中包含 F12 模态暂停、原生 Enter 调整技能、真实切割倍率变化、船体卡配置与退出恢复。截图是自动化证据，不是人工通关。

原阶段四的物流长跑超时、随机经济非有限向量和部分引擎退出清理报告仍见 `proofs/validation.md`，本次没有声称修复这些问题。

Jev 选择统一卡片工作台：条件概率 99%，小网格 0%，多窗口界面 1%，选择置信度 98%。实现判断是让作业、成长、合同各有清楚入口，并复用原有后端。
