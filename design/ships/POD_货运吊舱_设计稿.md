## 1. 和灰鹭号、雨燕拆起来不一样在哪

| | 灰鹭号 | 雨燕 | 货运吊舱 |
|---|---|---|---|
| 主要难点 | 气、电、液系统多 | 由外而内、气闸 | **货物本身**：重、杂、有的危险，货单可能不对 |
| 系统 | 多 | 齐全 | **很少**：一块电池、两个姿控推进剂小罐 |
| 拖运 | 中 | 少 | **最多**：6 个货柜 + 散装，按货单分拣送不同的口 |
| 用时 | 18–26 分钟 | 10–12 分钟 | 12 分钟左右 |

## 2. 布局（x 从前端 0 到 20 m，宽 6.4 m）

| 段 | 范围 | 内容 |
|---|---|---|
| F 前端 | 0–4 m | 航电 AV-P、电池 BAT-P、对接环 DOCK-P |
| H1 货舱一（最高） | 4–9.2 m | 货柜 CG-1、CG-2 |
| H2 货舱二 | 9.2–14.4 m | 货柜 CG-3（超重，3.5–4.2 t）、CG-4 |
| H3 货舱三（最低） | 14.4–20 m | 货柜 CG-5（危险品）、CG-6（散装：网兜里一堆小件） |
| 笼架 | 4–20 m | 立柱 + 顶梁 + 底部导轨（整排螺栓）+ 侧面斜撑；不是船壳，所以没有气压问题 |
| 外挂 | 顶部、船尾 | 三块顶部舱盖（电动铰链，带电时硬撬会烧电机）、吊装轭架 + 吊环（螺栓在笼顶）、两个姿控推进剂小罐 + 姿控喷口 |

- 货舱无压（真空），所以没有失压问题；考验集中在「怎么把货弄出来、送对地方」。
- 货柜用锁扣固定在导轨上（每个 4 把锁）；舱盖开了才能把货柜整件抓出来，不开就得切船壳。

## 3. 玩法要点

1. **先开舱盖**：舱盖电机由 BAT-P 供电，先断电再手动开；带电硬撬会烧电机（现有「电动舱盖」机制）。
2. **按货单分拣**：普通货柜 → 设备口（完整）；危险品货柜 → 危险品口；散装小件 → 熔炉（或碎屑网）。送错口按现有判定拒收或降价。
3. **超重货柜**：CG-3 超过 3 t 抓钩上限——买了 5 吨抓钩可整件拖走，否则要切开（价值大降）。这正好对应商店里 5 吨抓钩「改变的打法」。
4. **货单可能不对**：沿用现有陷阱（危险货物、带电货物、超重货柜等），由合同市场按星级挂上；情报包能提前看出一项。

| 合计 | | | 约 $45,000–70,000（看货） | |

- 零件约 40 件；船体本身很简单，价值大头在货。
- 合同：市场合同，1–3 星，标准用时 12 分钟；合同类型可以是整船拆解或抢救单（指定几个货柜）。
- 实现方式：只加数据（`ships/pod.json`），变体生成器的货物表扩到 6 个货柜位；不改系统代码。
