## 1. 定位

| | 灰鹭号 GR-7 | 远航者 ARK-01 |
|---|---|---|
| 尺寸 | 42 m | **约 600 m**；居住环半径 105 / 110 m；散热翼展 220 m |
| 外形 | 方盒货舱 | 440 m 长主轴（桁架 + 三层耐压管）、两个旋转居住环、120 m 工业块（带机库）、屏蔽动力核心 + 巨型散热翼、8 个推进剂球罐、五联引擎——一座会飞的殖民地 |
| 难点 | 系统多 | **多系统并行**：哪套还活着、哪个环有压、环还在转、主轴的力从哪里走 |
| 拆法 | 一次拆完 | **多日工程**：先消旋 → 分区隔离 → 逐区拆；每天收工保存全部物理状态 |
| 零件 | 102 | 约 1,500（按性能测试再定） |
| 一单用时 | 18–26 分钟 | 8–12 个工作日，每天 40–60 分钟 |
| 价值 | $125,100 | 约 $4,800,000 |

用户原则：这艘船的意义不是让玩家重复点 500 次，而是第一次真正像拆一个小型太空设施。路线图 6.3 的验收是：重复操作占比 ≤ 20%，工程决策占比 ≥ 80%。

## 4. 系统（多套并行）

- **旋转（新）**：两个环带着角动量进坞（约 3 rpm）。消旋：先断环内负载 → 用环毂的消旋电机 / 制动器把环刹停（制动电容会充电、会发热）→ 锁死轴承 → 才能进转运气闸、拆轮辐。
  - 在转的环上切东西：切下的零件会按切线速度飞出去。
  - 只刹停一个环：整船会被反扭（船坞夹具受力）。
- **电**：主反应堆（停）→ 电力分配中心 → 主轴主干 → L1–L12 局部配电 → 环毂滑环 → 环内。另有辅助电网（电池组）、B 环备用电池 + 发电机、L6 下层备用。多个电源互相不完全隔离。
- **气**：A 环、B 环、主轴、舰桥、工业块、动力核心各是独立大分区；环与主轴之间隔着轮辐门、旋转气密封、转运气闸。
- **水**：B 环水循环（停机后管里有残留水）、主轴下层水管。
- **结构受力（新）**：尾部（反应堆 + 引擎 + 推进剂）挂在 440 m 主轴上；主轴承力弦杆是受力路径，切一段力就要换路走。

## 5. 事故变体

| 事故 | 真实状态 | 证据 | 安全做法 | 做错的后果 |
|---|---|---|---|---|
| 两个环都还在转（每单都有） | 约 3 rpm | 环毂转速读数 / 看得见 | 先断环内负载 → 两个环对称消旋 → 锁轴承 | 在转的环上切件 → 零件甩出；只刹一个 → 整船反扭，坞夹具报警 |
| 某居住环已失压，另一环仍正常 | A 环破口、0 kPa；B 环约 100 kPa | 两环测点 | 两环分开处理：A 环直接拆，B 环先放气 | 打开 B 环的轮辐门以为也没压 → 冲击，温室玻璃顶被吹裂 |
| 主轴某层断电，但下层备用系统在运行 | L6 上层主干断了，下层备用电池在给设备供电 | L6 上层 0 V、下层有电压 | 断 L6 下层备用电池 | 切 L6 下层线束 → 打火 |
| 农业区水循环残留 | 泵停了，管里和水箱底还有水 | 管段低点 / 水箱液位 | 先用回收泵抽 | 切管 → 水在零重力里散开，泡坏附近电气（价值降） |
| 主反应堆已停，但辅助电网仍活着 | 辅助电池组给分配中心和部分负载供电 | 分配中心电压 | 断辅助电网总闸 + 放电 | 以为停堆就安全 → 切分配中心打火 |
| 结构切割影响长主轴受力 | 切断一段弦杆后，尾部重量全压到剩下的弦杆 | 受力预警；主轴应力读数 | 先拆尾部重量（推进剂、引擎、反应堆分段），再拆主轴；或先加临时支撑 | 先切主轴 → 后段下垂 / 扭转，撕裂整段 |

## 6. 需要新增的机制

1. **旋转部件 + 消旋**（新）：环带角动量；消旋机构；在转的部件上切割会让零件按切线速度飞出。
2. **多日作业**：收工 → 保存全部物理状态 → 第二天读档继续；合同按天计运营费。
3. **结构受力路径**：零件之间的受力传递（比现在的撕裂预警更全局）。
4. **滑环 / 旋转密封**：电和气跨过旋转面的接点。
5. **性能**：约 600 m、约 1,500 件。必须先用无美术测试船压测（6.3 已列）。还可能要做分区休眠：远处的区域不参与物理计算，玩家走近才唤醒。
6. **镜头**：600 m 的船要有全船总览视图和分区跳转。

## 7. 船坞、用时、价值

- 约 600 m：6.1 的船坞从 200 m 改为约 620 m。整艘进坞，不分段运输。
- 目标：8–12 个工作日；价值约 $4,800,000。
