## 1. 定位

| | 灰鹭号 GR-7 | 远航者 ARK-01 |
|---|---|---|
| 外形 | 方盒货舱 | 一根长主轴（桁架 + 内部耐压管）、两个旋转居住环（侧视看到每个环的上下两段 + 轮辐）、中段工业块、尾部屏蔽动力核心 + 散热翼 + 五联引擎阵列——一座会飞的殖民地 |
| 难点 | 系统多 | **多系统并行**：哪套还活着、哪个环有压、主轴的力从哪里走 |
| 拆法 | 一次拆完 | **多日工程**：每天收工保存全部物理状态，第二天接着拆 |
| 零件 | 94 | 约 600–800（按性能测试定） |
| 一单用时 | 18–26 分钟 | 4–6 个工作日，每天 40–60 分钟 |
| 价值 | $122,500 | 约 $1,600,000 |

**原则（用户）**：重点不是让玩家重复点 500 次，而是第一次真正像拆一个小型太空设施。重复操作占比 ≤ 20%、工程决策占比 ≥ 80%（路线图 6.3 验收）。

## 4. 系统（多套并行）

- **电**：主反应堆（停）→ 电力分配中心 → 主轴主干 → 各段局部配电 L1–L5 → 环毂滑环 → 环内。另有辅助电网（电池组）、B 环备用电池 + 发电机、L3 下层备用——**多个电源，互相不完全隔离**。
- **气**：A 环、B 环、主轴、舰桥、工业块、动力核心各是独立大分区；环与主轴之间隔着轮辐门和环毂门。
- **水**：B 环水循环（停机后管里有残留水）、主轴下层水管。
- **结构受力（新）**：尾部（反应堆 + 引擎）挂在主轴上；主轴的承力弦杆是受力路径。切断一段弦杆，力会换路走；换到撑不住的路就会撕裂。

## 5. 事故变体

| 事故 | 真实状态 | 证据 | 安全做法 | 做错的后果 |
|---|---|---|---|---|
| 某居住环已失压，另一环仍正常 | A 环破口、0 kPa；B 环约 100 kPa | 两环测点 | 两环分开处理：A 环直接拆，B 环先放气 | 打开 B 环的轮辐门以为也没压 → 冲击，B 环温室玻璃顶被吹裂 |
| 主轴某层断电，但下层备用系统在运行 | L3 段上层主干断了，下层备用电池在给某些设备供电 | L3 上层 0 V、下层有电压 | 断 L3 下层备用电池 | 切 L3 下层管线束 → 打火 |
| 农业区水循环残留 | 泵停了，管里和水箱底还有水 | 管段低点 / 水箱液位 | 先用回收泵抽 | 切管 → 水在零重力里散开，泡坏附近电气（价值降） |
| 主反应堆已停，但辅助电网仍活着 | 辅助电池组给分配中心和部分负载供电 | 分配中心电压 | 断辅助电网总闸 + 放电 | 以为停堆就安全 → 切分配中心打火 |
| 结构切割影响长主轴受力 | 切断某段弦杆后，尾部重量全压到剩下的弦杆 | 受力预警（现有撕裂预警的扩展）；主轴应力读数 | 先拆尾部重量（引擎、推进剂、反应堆分段），再拆主轴；或先加临时支撑 | 先切主轴 → 后段下垂 / 扭转，撕裂整段 |

## 6. 需要新增的机制

1. **多日作业**：收工 → 保存全部物理状态（自由零件、气压、电、液）→ 第二天读档继续；合同按天计运营费。
2. **结构受力路径**：零件之间的受力传递（比现在的撕裂预警更全局）；先用简化模型：主轴弦杆承担尾部重量，按剩余弦杆数分摊。
3. **滑环**：电力跨旋转面的接点；环是否还在转（见问题）。
4. **性能**：190 m、600–800 件；路线图要求先用无美术测试船压测（6.3 已列）。
5. 多电源互相不完全隔离：现有 own_supply 组合，加「同一线缆两端都有电源」的情况。

## 7. 船坞、用时、价值

- 190 m：需要 6.1 的 200 m 船坞；整艘进坞，不分段运输。
- 目标：4–6 个工作日；价值约 $1,600,000。
