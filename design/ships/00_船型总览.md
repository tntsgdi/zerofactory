## 实现顺序（审完后）

1. 阶段三：作业艇（开局）→ S-09 接入开局与市场 → 货运吊舱进市场 → H-22（先做液压 / 残磁 / 预紧件三个机制）。
2. 阶段四：船坞扩建 → MED-47 → M-14 → FR-26。
3. 阶段五：120 m 船坞 → VT-80 → PS-12。
4. 阶段六：200 m 船坞 → PT-34 → ARK-01（先用无美术测试船压测性能和多日存档）。

每艘：作者脚本 → ships/*.json → VALIDATE SHIP（静态 + 安全路径机器人实走）→ 变体与陷阱 → 合同市场 → 回归全套测试 → 导出 exe。
