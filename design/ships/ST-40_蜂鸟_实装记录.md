# ST-40「蜂鸟」竞速艇 · 实装记录（2026-10-20，备审）

新设计十艘之一（`design/ships/02_新设计十艘_设计稿.md`，Jev 选型 2.31 / 置信 0.33，低）。

## 实装

- 造船脚本 `tools/authoring/st40_author.gd` → `ships/st40.json`：80 件（设备 42）、152 个固定点、21 条线路、16 个控件、3 个舱。机身 40 m，加尾喷口 43.4 m；高 6.6 m。密度 22.9 件 / 100 m²。
- 外形：尖鼻锥 + 鼓包座舱罩（两块座舱玻璃）的楔形碳纤维机身，台阶式发动机舱，上下两片复合材料尾翼，尾部喷口。
- 舱室：
  - P 驾驶舱：抬高的座舱地板上是驾驶操纵台、抬头显示器、抗荷座椅、小型环控、灭火瓶；地板下是航电、竞速数据记录仪（合同指定件）、氧气柜；地板底下挂着接线盒和座舱备件柜。出入舱口在下巴斜面上。
  - E 设备舱：一氧化二氮氧化剂罐（高压气瓶）、两个燃料箱、800 V 竞速电池、逆变器、配电、冷却泵、遥测机柜、数据采集；顶上电池冷却板、惯性单元、显示屏、竞速应答机、摄像记录仪、灭火瓶、备件柜；顶上出入舱口。
  - M 发动机舱：主发动机、电动涡轮泵、发动机控制单元、点火电容（独立带电，要在控制单元上泄放）、灭火瓶。
  - 外面：喷口、鼻锥传感器、两组姿控、尾翼上的转播摄像吊舱。
- 线路：电池 → 配电 → 逆变器 → 涡轮泵；配电 → 遥测 / 航电 / 发动机控制 / 环控 / 灯；燃料和氧化剂管到涡轮泵；冷却回路串电池、冷却板、发动机。
- 所有可回收设备都不超过 3 t（发动机 2.6 t）。

## 特化：复合材料机身（新模块 `scripts/composite.gd`）

- 机身壁板（`HC` 开头）和尾翼是碳纤维复合材料，壁板之间用**螺栓**连接（不是焊），可以用扳手拆下来。
- 在旁边舱室还有空气时用激光切复合材料：放出有毒烟雾，留在那个舱的空气里（空气越多留得越多）。舱里有烟雾时，舱内电子设备（控制台、航电、机柜、配电、显示屏、记录仪等）持续掉价值，最低到 55 %；烟雾浓度过高时驾驶舱的座舱玻璃起雾（价值剩一半）。
- 把舱抽成真空，烟雾随空气一起排走；先抽真空再切，或者拆螺栓，就不会有烟雾。
- 设备舱里有烟雾浓度计（ppm）。
- 机器人：先抽空所有舱再拆，不会产生烟雾。

## 测试

- VALIDATE SHIP st40：13 项全过。
- `tests/st40_check.gd`：10 项全过（机腹是复合材料；带空气切机腹 → 设备舱冒烟、遥测被熏坏、座椅不受影响、浓度计读数；驾驶舱旁切两刀 → 座舱玻璃起雾；抽空 → 烟雾随空气排掉、存档；先抽空再切没有烟雾；拆螺栓卸尾翼没有烟雾）。
- 机器人：回收率 99.95 %，无事故。
- 随机合同 24 张，0 张丢弃，抽 8 张实拆 8/8；带消防瓶事故的 3 张 3/3（消防瓶插槽在发动机舱尾部；起初放在设备舱和遥测、数据采集重叠，所有合同都被丢弃，已改）。
- 市场：ST 级「蜂鸟级竞速艇」，声望 16 起出现；标准用时 24 分钟；合同价值 $456,700。
