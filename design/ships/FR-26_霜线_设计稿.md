## 4. 系统

- **温度（新）**：每个罐有温度和「真空夹层完好度」。夹层好：漏热很慢；夹层坏：漏热快 → 货沸腾 → 罐压上升 → PSV 开启排放（PSV 好的话）。
- **低温管网**：罐与罐双层总管相连，隔离阀在电控阀箱里控制；管子可能「冻住」（阀门卡死、管内冰堵）。
- **制冷**：CHILLER-1/2 维持罐温；断电后罐会慢慢升温（物理过程，不是倒计时；用户定：可以，但要升得慢——一单之内，正常拆法不会因为升温出事，拖太久或夹层坏了才会）。
- **蒸发气（BOG）**：蒸发出来的气由压缩机送去再液化；压缩机停了，罐压靠 PSV 排放塔泄掉。
- **加热**：HEATER 用来化冰；它被错误启动时会把某个罐加热 → 升压。
- **电**：前后两个配电，尾部配电箱；备用电池给 CHILLER-2 和 HEATER。

## 5. 事故变体

| 事故 | 真实状态 | 证据 | 安全做法 | 做错的后果 |
|---|---|---|---|---|
| 某罐已失真空层 | T-2 夹层漏了，漏热快 | 外壳结霜 / 壳体温度低；T-2 压力比另外两个高且在涨 | 先给 T-2 泄压回收（回收泵），再处理别的 | 不管它先拆别的 → T-2 PSV 一直排（损失货），或 PSV 坏时罐体超压 |
| 一段管线冻住 | T-1→T-2 之间一段总管冰堵 | 管路两端温差 / 压差；阀门动作无响应 | 用霜冻排放接口 + 局部加热化开，再关隔离阀 | 直接切冻住的管 → 低温液喷出，冻坏附近设备（价值降） |
| 备用加热器错误启动 | HEATER 被备用电池供着，在加热 T-3 | T-3 温度在升；HEATER 电流读数 | 断备用电池到 HEATER 的支路 | 不发现 → T-3 升压到 PSV 开启 / 超压 |
| 安全阀冻结卡死 | PSV-1 冻住，打不开 | PSV 位置读数不动；罐压已超设定但没排 | 先手动泄压（排放管上的手动阀），别切罐 | 切罐体 → 超压罐爆裂 |

## 6. 需要新增的机制

1. **温度状态**：罐 / 管 / 设备的温度，与压力联动（升温 → 升压）；真空夹层完好度。
2. **冻结**：阀门 / 管段的「冻住」状态（无法动作），加热后恢复。
3. **低温液回收**：新的回收口或用现有回收泵 + 新货类。
4. **超重罐**：空罐 6–8 t，要分段或等 4.4 的重型起重。
