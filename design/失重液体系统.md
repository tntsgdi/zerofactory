# 失重液体系统（2026-10-20）

用户要求：“不能只说有液体，要表现出真实的液体……太空中液体的悬浮感”。

以前的情况：管路或液罐被切开，只在后台扣液体量、弹一句提示，燃料多一团看不见的可燃云，画面上没有液体。

## 定案

用户全部选了推荐项，Jev 判断一并列出。

| 问题 | 定案 | Jev |
|---|---|---|
| 做到什么程度 | 液团：每团有位置、速度、体积，按表面张力抖动，会合并、溅开、贴附，按液体种类蒸发或沸腾 | A 0.93 / 置信 0.89 |
| 低温液体 | 闪蒸：一部分喷出即成白汽，其余边漂边缩、拖蒸汽尾，碰到的表面结霜；液氦最快 | A 0.98 / 0.97 |
| 玩法影响 | 轻度：带电设备沾上会短路受损，燃料液团被激光扫到起火，低温液团冻裂设备，无人机撞上低温液团结霜 | A 0.81 / 0.72 |
| 区分方式 | 保持三色风格，靠质感区分 | A 0.86 / 0.79 |
| 出现场景 | 所有泄漏、BL-88 水球破裂、DR-150 泥浆喷出、HG-170 放空和爆罐、FX-70 失超、DC-84 冷却液泼洒；残液变体以后再做 | — |

## 实现（`scripts/liquids.gd`）

- **运动**：
  - 没有重力，液团保持动量。
  - 舱里有空气时有二次空气阻力：a = 3/8 · Cd · (ρ空气 / ρ液体) · v² / r。水几乎感觉不到阻力，轻得多的液氢小液滴会被明显拖慢；真空里没有阻力。
- **表面张力**：液团画成会抖的球。小液团圆而稳；大液团抖得慢、幅度大，抖动频率约与 r^-1/2 成正比，并随时间衰减。
- **合并**：两团慢慢靠近、接触后合成一团，体积相加，动量守恒。正在飞散的碎团（例如刚炸开的水球）和高速擦过的不合并；刚生成的 0.5 秒内也不合并。
- **碰撞**：
  - 撞上结构时速度超过该液体的碎裂速度，就溅成 2–4 团反弹出去；
  - 低于碎裂速度就贴在表面上，摊成一层液膜，跟着那个件走（件被拆走，液膜也跟着走）；
  - 冰球直接弹开。
- **各种液体**：

  | 液体 | 真空中 | 有空气时 | 其它 |
  |---|---|---|---|
  | 液氦 | 每秒沸掉 30 % | 每秒 45 % | 喷出即闪蒸 45 % |
  | 液氢 | 每秒 12 % | 每秒 22 % | 闪蒸 25 % |
  | 液化天然气 / 液氮 | 每秒 5–7 % | 每秒 9–12 % | 闪蒸 12–15 % |
  | 水 | 6 秒后冻成冰球，冰球缓慢升华 | 缓慢蒸发 | — |
  | 燃料 | 慢慢挥发 | 慢慢挥发 | 被激光扫到会起火，接现有可燃云火灾 |
  | 乙二醇冷却液 | 几乎不挥发、不结冰 | 同左 | — |
  | 钻井泥浆 | 不蒸发 | 不蒸发 | 不碎裂，落哪粘哪 |

- **画法**：
  - 低温液体：细亮边，内部有成核沸腾的气泡上浮，带蒸汽，碰到的表面留下霜花（24 秒后消失）。
  - 燃料：粗边，内部有旋转的油膜纹和高光。
  - 水：干净的边加左上高光。
  - 乙二醇：在水的基础上多一道内圈。
  - 泥浆：实心暗色，带颗粒。
  - 冰球：多面体，不抖。
  - 泄漏口：先喷出一股液柱，液柱上的颈缩波越往前越大，最后拉断成液滴（Plateau-Rayleigh 不稳定）。低温液体的液柱外还裹着一团汽雾。
- **玩法**：
  - 带电设备沾上液团会短路，最多掉 8 % 完好度（泥浆除外）。
  - 低温液团会冻伤设备。
  - 无人机撞上低温液团受轻伤。
  - 这些都只记损失，不算事故。
  - 模块自己已经结算过损失的泼洒（水球破裂、泥浆喷出等）标为“quiet”，不再重复伤害。
- **液体外观的来源**：船文件里液体体积的 `look` 字段（lh2 / lhe / lng / ln2 / water / fuel / glycol / mud），没有的话按液体种类推断。HG-170 罐里是液氢，FX-70 杜瓦里是液氦，DR-150 立管里是泥浆。
- **性能**：上限 320 团，按网格查找合并对象；远离船体的液团不做碰撞检测。300 团约 3.9 ms 一步，测试机上同时还开着其它会话。
- **不存档**：读档后，漂着的液体就没了。
