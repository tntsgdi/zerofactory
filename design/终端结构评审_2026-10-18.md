# 终端结构评审（2026-10-18）

## 起因（用户原话）
「为什么我点合同市场也是弹到设备商店？我觉得这个界面的结构可以重做一下，不一定要左边两台电脑。居然两台电脑是打开同一个东西的，感觉怪怪的。你让 Sonnet 作为玩家给出他的评价。」

## 查到的原因
- 左边两台电脑（「设备商店」「船坞管理」）打开的是同一个四标签终端，只是起始标签不同。
- 现场不能签合同，所以「合同市场」标签照样显示，点它却被强制跳到「设备商店」：看得见、点不了、还悄悄跳走。
- 现场买的东西只有技能书当场生效；设备、设施、消耗品都下一单才生效。

## Sonnet 以玩家身份的评价（摘要，截图见 tests/out/cs_*.png 等）
按严重程度：
1. 两台电脑标签误导，打开的是同一个东西。
2. 点「合同市场」没反应、没提示，被偷偷换成别的页。
3. 「何时生效」只写在页脚小字里，现场花了钱不知道这单能不能用。
4. （【待写】占位：属用户待写文案，不算问题。）
5. 技能书键盘焦点样式和「已选中」一样，容易看错。
6. 「船坞管理」页是杂物间（还贷 + 重玩训练 + 设施），大片留白，设施字太小。
7. 主线合同卡缺「预计净赚」，不好和另两张比。
其他：「船坞管理」标牌压在大号「07」上对比度低；商店图例、声望进度字太小；商店两条满格仪表含义不明；合同卡底部货物清单太小太灰；技能书页标题重复资金。

推荐方案：
- 作业中取消两台电脑，用一个快捷键打开精简的现场面板，只有「技能书」和「消耗品」两页；顶部写明「装备和设施：两单之间开放」。
- 两单之间保留全屏终端，标签改为：合同 / 装备（升级 + 消耗品 + 船坞设施）/ 技能书 / 财务（贷款）；「重玩训练」挪到标题和暂停菜单。
- 次选：保留一台「补给终端」电脑打开同一个精简面板；或现场只开技能书。

## Jev 参考
- 现场入口：A 快捷键 + 精简面板（技能书 + 消耗品）0.99（置信度 0.99）。
- 两单之间的标签：A 合同 / 装备 / 技能书 / 财务 0.99（置信度 0.98）。

## 用户决定（2026-10-18）
- 现场入口：**快捷键和终端电脑都能打开**（同一个现场面板）。
- 两单之间的标签：**先调研同类回收游戏的 UI 再设计给用户审**。
- Sonnet 提的小问题：**先只改结构**，小问题进 TODO。

## 同类游戏调研（2026-10-18）
- Hardspace: Shipbreaker：两班之间回宿舍舱（HAB），选墙上的终端 / 工作台交互（消息、升级、债务）；评测吐槽早期在热点间走来走去笨拙，后改为直接选择。
- Ship Graveyard Simulator：办公室笔记本买船（买船即解锁合同）；升级要先付钱再去另一处兑换，玩家嫌繁琐。
- Car Mechanic Simulator：随身「快捷平板」（T）+ 订单（O），作业中随时调出。
- PowerWash Simulator：一台平板管工作与商店，2 代平板可替代地图直接开工。
- 共同规律：**一台设备、分区清楚**，作业中用同一台设备的快捷入口，不在世界里摆多台功能重复的机器。

## 三个结构方向（效果图 tests/out/struct_a / a_site / b / c.png）
- A 平板式：首页是应用磁贴（合同、装备、技能书、消耗品、账本、路线、无线电、训练舱）；现场按 B 或靠近电脑打开同一台终端，能用的排在前面，用不了的上锁并写原因。
- B 工作台式：首页是船坞示意图上的几个「站」。
- C 标签式：合同 / 装备 / 技能书 / 账本四个标签，路线、无线电、训练放右上角。
- Jev：A 0.63 / C 0.33 / B 0.04（置信度 0.45）。

## 定案并实现（2026-10-18）
用户选 **A 平板式**。首页 8 个应用磁贴（合同 / 装备 / 技能书 / 消耗品 / 账本 / 路线 / 无线电 / 训练舱，数字键 1–8 直达）；头部「首页 › 应用」加「← 首页」，应用里 Esc 回首页，首页 Esc 才退出。装备 = 升级件 + 船坞设施；消耗品单独一页；账本 = 贷款 + 最近合同。现场：墙上只留一台「船坞终端」，随时按 B 也能打开同一台终端；合同、装备、账本、训练舱上锁并写原因，点了被拒绝；现场不卖下一单才生效的东西；现场买的消耗品直接进本单库存。
