# ZERO PRESSURE：技能书与职业成长系统

实现基于 `factory/claude/youthful-hamilton-qb01vp` 的 `bd23934`，工作分支 `codex/growth-skillbook-20261017`。

## 玩家循环

选择一条自己需要的工法 → 将下一卷设为攒钱目标 → 拆船并结算现金与声望 → 回船坞买技能书及配套模块 → 当场使用新能力 → 接更复杂的船、配置船坞自动化。

只有现金一种购买货币。每卷包含知识授权和配套改装，购买后永久装配，不是一次性消耗品。六类 15 条路线，各 3 卷，共 45 级。路线之间自由选择，同一路线必须逐卷购买。

## 解锁与节奏

- I 基础卷：无需声望或完工数门槛，6,000–38,000。作业艇结算后即有可买的成长。
- II 专业卷：前一卷、完成 3 单、声望 6；36,000–97,500。
- III 专家卷：前一卷、完成 8 单、声望 16；225,000–495,000。通常需为专长攒数单，不能一单买满。
- 完工数与声望都使用现有合同结算。失败合同可能使声望不足，但已经购买的能力不会被收回。
- 不提高拆船收入，不降低船的危险，不用增加敌人血量或加长工作来制造成长。
- 下表价格是每一卷的增量价格，不是累计价。全部路线总花费 6,354,500；玩家更适合先专精一两类。

经济依据：本次谨慎拆船自动回归的样本中，作业艇净入约 43,107，雨燕约 103,474，中期灰鹭 / 双钩约 14–17 万，吊舱 / 作业艇小单约 3–5 万。这是测试机器人样本，不能当成人类玩家平均收益。III 的典型中型合同储蓄周期约 2–4 单，损失和借款会延长周期。

## 界面与操作

船坞终端新增第 4 页“技能书”，数字 4 打开；现场两台电脑也能切到此页。左侧按六类列出所有路线和已掌握等级，滚轮可浏览；右侧给出当前与下一卷对比、三卷数值及价格、前置条件、购买 / 满级 / 缺钱 / 未解锁状态。支持鼠标、Tab 焦点和 Enter；Esc 回终端标题或关闭现场终端继续原作业。列表和详情分别滚动，适应不同视口。

攒钱目标保存在当前生涯槽内，终端顶栏持续显示缺口或解锁条件；开局合同市场的资金用途列表优先显示它。满级后标记已学满，可另外选择目标。原设备商店保留消耗品及旧设备，船坞管理保留机械臂、拖船、泊位等设施。

无人机装甲、推进器和护盾以不同数量的结构件显示在真实机体上；抓钩梁的股数随吨位提高。技能书内有随装配变化的无人机示意图与工具类别装配计数。其他升级以详情中的明确数值展示。

## 存档与现场生效

`Growth` 是目录、定价、解锁与购买事务的唯一来源。等级写在现有 upgrades 字典的 `skill_*` 键中，目标写在 `growth_goal`；仍使用原校验和、临时文件替换和 .bak 回退保存机制。

旧 `grapple5` / `pump2` / `scan_kit` 分别计为重载抓钩 / 高效泵组 / 精密检测 I，按下一卷收费。原商店买来的设备继承原有“下一单装配”规则；技能书购买明确“本单立即可用”。购买只在现金足够时进行，不借贷。失败写盘恢复原资金、等级与当前合同装配；成功才通知现场更新。继续同一生涯同一合同时，新技能优先于较旧作业快照，避免购买后未自动保存作业就退出导致能力消失。其他生涯槽、训练和考核不受装配影响。

## 能力边界

这是对现有物理工具的强化：高阶抓钩仍不能拉动超吨位整体；扫描仍需可见目标，封舱不透视，读数仍会失效；激光仍会切断管线、触发带电 / 压力危险；护盾不能替代断电；维修剂消耗库存，机库维修继续免费。全部原有固定件类型仍可用，快拆提高操作速度，不把已有基础操作重新锁起来。

没有新增会耗尽的电池 / 激光过热条，也没有把本来已支持的多条读数和多管回收改成收费解锁。无人机续航通过装甲与维修效率体现；激光危险通过隔热保护处理。若以后加入能量 / 热负荷系统，应先证明它产生有意义的作业选择，再设计对应扩展卷，不能用额外补给负担强迫玩家购买。
