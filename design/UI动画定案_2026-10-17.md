# UI 华丽动画定案（2026-10-17，用户两轮问答确认）

用户原话：「继续优化 UI。目前 UI 还不是很酷炫，你需要有极其华丽的动画：极简风格配合的华丽动画、精美的动画，以及机器人必然的一看就感觉很牛逼的动画。」排在手感 P.1–P.6 之后（已完成）。

## 第一轮
1. 范围：**全部**——无人机、终端菜单、场景转场、HUD、拆解时刻。
2. 无人机：机械动作 + 能量特效 + 姿态 + 登场，**全要**。
3. 特效强度：**完整**（辉光、粒子、拖尾）。
4. 设置：加「动画强度」三档：**完整 / 精简 / 关闭**。
5. 参考：无。

## 第二轮
1. 无人机：**重新设计外形**（概念图 tests/out/drone_concepts.png，三个方向：A 环核 / B 楔形 / C 三爪，用户挑选后实现）。碰撞体不变（半径 20）。
2. 切换工具时**五种工具都变形**（约 0.25 s）：激光发射器伸出、散热片发热；抓钩线圈转起；测量仪扫描环；维护机械臂展开；回收口打开。
3. 转场：**热线合上**（加火花与冲击波）+ **蓝图展开**（网格线扫过，新场景一笔笔画出）。
4. 终端 / 菜单：**开机自检式**——面板先描边、再填充、文字打字进入，错峰 0.3–0.5 s，带轻微扫描线（Jev 0.87，未单独询问）。
5. 设置关系：「动画强度」与现有「震屏 / 闪白 / 顿帧」**两个都留**；动画强度设为「关闭」时连带关掉震屏闪白。

## 第三轮（外形）
- 用户先选「混合两款」：A 环核 + C 三爪，并要保留旋转外环 + 偏转喷舱、箭头机身 + 双主推、关节机械爪、分瓣光圈镜头 → 两个混合稿（tests/out/drone_concepts_mix.png）。
- 玩家无人机 R-02：**H1 箭环**（长箭头底盘，环核嵌在中间偏后，翼尖双主推，翼侧偏转喷舱管侧推和刹车，鼻部两侧口器式机械爪夹着工具头）。
- 用户：「都挺好看的，多个无人机就选不同的」→ 搬运无人机 1 号用 H2 核爪，2 号（就是高级版）用 C 三爪；B 楔形、A 环核备用。

## 实现约束
- 程序化绘制，不加外部美术资源；无人机画法集中在 scripts/drone_art.gd。
- 「精简」档：保留动作，去掉粒子、残影、大面积辉光；「关闭」档：界面瞬时切换、无转场动画、连带关震屏闪白。
- 动画不能挡住操作读数；性能以 tests/perf_stress.gd 的相对变化为准（这台机器上的绝对值偏高）。

## P.7 终端重做（2026-10-18）

## P.8 路线页 + 下一个目标（2026-10-18 用户定）
- 三稿（tests/route_concepts.gd：A 声望阶梯 / B 四栏分类 / C 节点路线）里选 **C**。Jev：布局 B 0.48（置信 0.31，太低，交用户）、目标选法「玩家钉选」0.80（置信 0.70，采纳）、位置「标题栏内」0.58（置信 0.37；标题栏只剩约 220 px 放不下两条，按用户定放面包屑行右侧）。
- 地图（scripts/route.gd 出数据，terminal.gd 画）：上面两排是钱能买的 13 件升级件和设施，便宜的在前，已装好的变暗；中间是 8 艘船按生涯遇到的顺序连成线（开场三艘在前，再按声望），已开放的一段亮绿、下一艘橙色呼吸；船坞扩建连线到要它的大船（M-14、MED-47、FR-26），第二台搬运无人机连到第一台；下面是声望刻度（见习 / 认证 / 资深 / 首席等距），技能书第 II、III 卷挂在刻度上，「你 · 声望 N」标在下面。
- 下方详情：选中节点的每个条件一根进度条（声望 7 / 8、要船坞扩建、合同市场），再一句接下来会怎样（会出现在合同市场 / 到「装备」购买 / 技能书里能买）。
- 钉选：Enter 或再点一次 = 钉 / 取消，最多两条，第三条把最早的挤掉；技能书的「设为攒钱目标」占其中一条，路线页取消它也清掉技能书的目标；钉的存在生涯（route_goals）。达成的目标自动退出，空位显示离达成最近的（先显示还没攒够的，买得起的只补空）。
- 面包屑行右侧每一页都有「下一个目标」两条：★ 名字、还差多少、进度条；点一下跳到路线页那个节点（技能目标跳技能书）。首页「路线」磁贴写第一条目标。现场打开时标题栏「在线」换成「现场 · 已暂停」。

## 丝滑程度（2026-10-18 用户定）
用户：「继续优化 UI、动画还有丝滑程度，现在 UI 还是不够丝滑」。先量（tests/smooth_probe.gd）：终端每页 2–11 ms 不卡，是动作生硬；游戏内每帧约 13.5 ms，P99 19.6 ms，飞行时会连续几帧超过 20 ms。用户按推荐全做（Jev：切页 A 0.60 置信 0.40；选中框「跳」0.83、数值「瞬变」0.71，与「要丝滑」相反，按用户定）。
- 切页：共享轴滑动。旧页 0.12 s 往一边滑出淡出 40 px，新页 0.04 s 后 0.22 s 从另一边滑进；方向按首页 → 磁贴顺序；技能书（独立控件）一起滑；面包屑文字交叉滑动，「← 首页」跟着淡入淡出；底部按钮跟新页淡入。动效「精简」只淡不滑，「关闭」全部瞬切。
- 选中框：每页只画一个，用弹簧从旧项滑到新项（含悬停抬起），换页时直接落在新页的项上，不跨页飞。
- 数值：路线页方框 / 详情 / 顶部目标 / 声望的进度条约 0.3 s 缓到新值，进页面时从空填起（顶部的两条不重填）；按钮文字换时上下交叉淡入 0.16 s。
- 游戏内帧时间：搬运无人机在屏幕外不画；无人机在屏幕上每个美术单位不到 1.4 px 时省掉看不见的小细节（灯点、关节小圈、光圈叶片、爪尖）；传送槽的箭头、履带条、吸入箭头各合成一次绘制（原来每帧约 200 次调用）。结果：中位数 13.5 → 11.7 ms，P99 19.6 → 15.8 ms，超过 20 ms 的帧 0。
- HUD：本来大多有动画；鼠标下物件标签离开时改成 0.12 s 淡出，不再瞬间消失。

## 标题页与存档页（2026-10-18 用户定）
- 视差 + 检测灯：船、星尘、标题按鼠标分层轻移（远的星尘动得少）；鼠标下一圈柔光，照到的船体线条变亮，所在的舱高亮并标出舱名（A 驾驶舱 / B 生活舱 / C 货舱 / D 电力舱 / E 维修舱 / 推进段）。
- 菜单：一条高亮条用弹簧滑到鼠标或方向键所在的项，字距拉开一点；按下下沉回弹，悬停、按下有声音；↑↓ 也能选。
- 开始 → 存档：镜头推进，船放大、船头和推进段冲出屏幕，货舱撑开成存档卡的外框，星尘变成从中心往外的流线；标题和菜单在推进前段就淡出；卡片在货舱撑开后错开升起、带一点回弹；返回时反着拉出来。
- 存档卡：鼠标下的卡朝鼠标倾斜（靠鼠标的一边下沉）、微微放大，一道斜光泽跟着鼠标扫过；资金、单数、时长在卡片出现时滚动数上来。
- 动效「精简」只淡入淡出不推进不倾斜，「关闭」直接切；测试用 pointer_override 代替鼠标，绝不移动真实鼠标（tests/title_motion_shot.gd）。

## 转场重做（2026-10-18 用户定，参照 NANOFALL / 共振 / 天穹防线）
测出来旧转场：场景离场 0.3–0.45 s → 黑幕合线 0.42 s → 同步换场景冻 0.19 s（进树 120 ms + 首帧 70 ms，tests/scene_load_probe.gd）→ 蓝图格子打开 0.7 s，合计 1.6 s 以上、穿黑、还卡一下。兄弟项目：不黑屏、0.2–0.45 s、新旧重叠、行依次落下、按钮倒墨。
用户选：先做 A 快照转场（以后再做 B 合成一个场景），一般切换上浮淡出、接单折成细线，按钮用倒墨（Jev：B 0.74 置信 0.61 / 上浮 0.76 / 倒墨 0.70）。
- scripts/wipe.gd 重写：切换那一刻把画面截成静帧盖在最上面，新场景在静帧后面建（0.19 s 的卡落在不动的画面上，看不出来），新场景画出两帧后静帧上浮 26 px 淡出（0.26 s）。截图与实际像素一致（tests/wipe_shot.gd 对比）。
- 接单（终端 → 船坞）：卡片抬起 0.12 s 后，整屏以那张卡为中线先压扁（0.2 s）再收窄（0.18 s，重叠 0.06 s）、越压越亮，成一条热线；此时换场景；船坞从这条线上下拉开（0.34 s）。
- Wipe.busy() 只在画面被遮住时为真；Wipe.arrived() 在转场切进来后 0.9 s 内为真，新场景据此跳过自己的开场（hud.gd 的黑条开场要加这个判断，请切割环会话改）。
