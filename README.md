# 零压拆船厂 / ZERO PRESSURE — Demo

双击 **build/ZeroPressure.exe**，或在 Godot 4.7 打开本目录按 F5。

拆解合同 #001：在真空船坞里拆掉 42 米的事故货船 GR-7「灰鹭号」。先测量，再隔离危险，最后切开、拖走、回收。

## 操作
- **WASD** 喷气移动（真空惯性：松手会一直滑）· **Shift** 冲刺 · **Space** 全向反推刹停
- **鼠标** 瞄准，**左键** 使用当前工具（作用距离 4 m，只能作用于看得见的地方）· **右键** 松开抓钩 / 取消
- **1 测量**：点测压口、测点、线缆、零件，得到带仪器/测点/时间的读数；系统变化后读数会变灰过期
- **2 激光切割**：自由切割，切线追着光标走；碰到设备会停下，再按一次左键才切入（切进去就成废料）
- **3 磁力抓钩**：最多 3 t；按住拖，松开即甩出；回收口会把飘近的东西吸进去
- **4 维护工具**：拧螺栓、解锁扣、拔插头、开关阀门与电闸、松开船坞夹具
- **5 气液回收**：软管接口，后台抽气 / 抽液；再按 5 切换「回收 / 排放」
- **Tab** 出厂图纸 · **C** 合同 · **H** 提示开关 · **滚轮** 镜头远近 · **Esc** 菜单

## 回收口
- **设备回收**（上方）：完整设备全价，不收废料和含危险残余物的东西
- **金属熔炉**（下方）：什么都收，按重量算废金属；带危险残余的扔进去会爆燃
- **危险品回收**（右下）：没排空的储罐、带电的电容
- 小于 0.1 t 的碎块会自动飞进左下角的碎屑收集网

## 开发者模式（F12）
任何界面按 **F12** 开 / 关（记在设置里）。右侧面板列出这里能用的功能，**按 F 键或直接点那一行**都行。
- **现场**：F1 透视真实状态（舱压、储罐、电源、带电线缆标黄、磁场和预载、事故落点、作业方案和船坞机器状态）· F2 一键排空断电（含消磁）· F3 全部零件脱落 · F4 无人机无敌 · F5 时间 ×1 / ×2 / ×4 / ×8 / ×¼ 轮换 · F6 打开全部舱室 · F7 消耗品各 +3 · F8 立即结束合同 · F9 查看指针下的零件（名称、质量、价值、完好度、去向、固定方式、线路、电压 / 液体 / 温度 / 磁场）· F10 这一单从头再来
- **终端**：F1 资金 +$100,000 · F2 清空欠款 · F3 声望 +5 · F4 全部升级与设施 · F5 消耗品各 +3 · F6 刷新报价 · F7 单陷阱合同 · F8 跳过开局合同（直接开放市场）· F9 清空作业方案
- **标题**：F1 跳过训练（直接持证）
- **测试合同…**（三处都有）：选船型、事故（只列这艘船能放的）、风险星级、范围、目标、升级、变体种子，边选边过合同验证器；「开工」以沙盒方式直接开打（不结算进生涯、不覆盖生涯的进行中存档，打完回到开始的界面），在终端还可以「放到第 1 张报价」当正式合同接。

## 开发
- 设计定案：design/DECISIONS.md；待办：design/TODO.md
- 音效：`G:/audio_library/venv/Scripts/python.exe tools/make_audio.py`（合成 + Sonniss 素材）
- 字体子集：`python tools/subset_font.py`
- 测试（不抢焦点）：`tools/run_test.sh tests/<name>.gd --fixed-fps 60`
  - full_run.gd：机器人按规程拆完整艘船并结算（`-- careless` 全扔熔炉）
  - scenario.gd / input_check.gd：测量、切割、失压、抓钩、扳手、货舱门
  - save_check.gd：存档往返（使用独立测试存档，不碰玩家存档）
  - ui_shots.gd / wide_shot.gd / perf.gd
- 背景音乐：把 Suno 生成的曲子放到 assets/music/main.ogg 即可替换合成环境声
